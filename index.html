What This Is

ARCHIVE 是一个本地优先的个人物品索引。它不是商店，也不追踪真实购买记录——只是把你曾经选择过的东西，安静地放在一页里。

示例藏品仅供演示版式。点击 Add Object 或 Start Your Own Archive，数据会保存在本机浏览器 localStorage，可随时 Export / Import。

  • Privacy 数据不出你的浏览器，除非你主动导出 JSON。
  • Backup 更换设备前请 Export。清理站点数据会丢失本地档案。
  • Deploy 纯静态站点，可直接挂到 GitHub Pages。
